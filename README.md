# AI 桌面工具集

面向 Windows 的桌面工具与视觉实验仓库。每个子目录都是独立项目，拥有自己的
源码、依赖、运行方式和说明文档；使用某个项目时，进入对应目录单独配置环境即可。

## 子项目

| 项目 | 功能 | 文档 |
|---|---|---|
| `cat_pet` | 桌面悬浮宠物，支持摄像头人体/姿态检测和专注提醒 | [查看说明](cat_pet/README.md) |
| `virtual_camera` | 将图片或视频输出为 Windows 虚拟摄像头，便于测试视觉应用 | [查看说明](virtual_camera/README.md) |

## 仓库约定

- 各项目独立维护依赖，不建议在仓库根目录统一安装。
- 子项目的使用、配置、测试和打包说明保存在其根目录 `README.md`。
- Python 虚拟环境、构建产物、模型权重和运行日志默认不提交到 Git。

## 快速开始

选择一个子项目并阅读其文档：

```powershell
cd cat_pet
# 或
cd virtual_camera
```

当前项目主要面向 Windows；具体 Python 版本和系统组件要求以各子项目文档为准。
