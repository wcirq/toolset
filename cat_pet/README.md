# Cat Pet — 酷炫小猫悬浮窗

Windows 桌面悬浮宠物，结合摄像头人体/姿态检测，在检测到多人时自动切换到指定
程序，可用于防摸鱼、隐私提醒和专注场景。

## 主要功能

- HOG/Haar 或 YOLO 人体检测，支持通过姿态模型统计头部关键点。
- 多人持续出现后切换目标程序，支持触发冷却和目标窗口最大化。（摄像头识别人，自动切换工作到软件）
- 记录原窗口，可用快捷键或人员离开后的延迟任务自动切回。
- 右键启用或暂停监控；暂停时释放摄像头。
- 可在全屏游戏、会议或演示期间自动暂停监控。
- 摄像头预览、视频画面和检测标注可分别设置透明度。
- 区域截图支持窗口候选、自由框选、选区移动及四边/四角尺寸调整。
- 框选时提供带十字准星的像素放大镜，并跟随显示坐标、HEX 和 0～255 RGB 颜色值。
- 截图支持复制、置顶贴图、本地 RapidOCR、OpenAI-compatible OCR，以及独立的
  OpenAI-compatible/讯飞机器翻译。
- 两级形象选择：猫类下保留多种猫形象和配色；人类下提供与六套猫咪主题色对应的原图、卡通和抽象宝宝形象。
- 各类形象均支持动画、缩放和贴边形态。
- 宠物可吸附到软件窗口四角，跟随移动、调整大小、最大化/还原；支持拖离解绑。
- 吸附到 Windows 文件资源管理器时，可读取并复制当前文件夹路径。
- 可手动锁定资源管理器当前标签页的目录，进入其他目录后自动退回（防误操作，非权限限制）。

## 环境准备

项目以 Windows 和 Python 3.13 为目标。建议使用独立虚拟环境：

```powershell
cd cat_pet
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

主要依赖包括 PyQt5、OpenCV、NumPy、RapidOCR、ONNX Runtime 和 pywin32（读取资源管理器目录）。YOLO 与本地
OCR 共用 ONNX Runtime，不再依赖 Torch、Torchvision 或 Ultralytics。

## 运行

```powershell
python main.py
```

也可以双击 `run.bat`；该脚本当前使用 WorkBuddy 默认环境中的 Python，换到其他电脑或
虚拟环境时请改为对应的解释器路径。如需使用图片或视频模拟摄像头，可配合仓库中的
[Virtual Camera](../virtual_camera/README.md) 项目。

### 软件窗口吸附与解绑

按住宠物拖到其他软件窗口上，会显示候选窗口边框、四个角和四条边的中点。靠近一个位置后
会展开落点：四角提供 2×2 四格，可选择水平/垂直向内或压住角点的组合；四条边提供
压住边缘、软件内两档，不再提供完全位于软件外的落点。把宠物移入目标矩形后松开即可绑定；
未命中矩形时仍是自由移动/原有屏幕贴边。
提示使用与当前宠物窗口相同大小的落点矩形，拖动中的选中矩形就是松开后的实际位置，
不再使用与最终位置比例不同的固定小方格；相邻落点矩形允许重叠，以虚线边框区分。
左右垂直边缘的吸附位置会随拖动在 Y 轴连续移动，上下水平边缘会沿 X 轴连续移动，
位置按窗口尺寸保存为比例，因此窗口调整大小后仍保持相对位置。向边缘的垂直方向移出有效范围会取消
该边缘选择；滑到边缘端点会自动进入对应角落的 2×2 二次选择。进入二次选择后当前目标软件临时锁定，
只有离开整个选择区域才重新检测其他软件。
吸附后右键宠物会直接显示吸附专用菜单，可关闭拖动提示、切换四角或主动脱离，
不再显示截图、设置、互动等通用操作；解绑后恢复完整右键菜单。
托盘仍保留完整菜单，吸附相关操作位于“软件窗口吸附”子菜单。

- 绑定的是具体窗口，不是整个程序；同一软件的多个窗口分别识别，不会因为重启软件自动重绑。
- 绑定后跟随窗口移动、调整大小和最大化/还原。目标最小化或隐藏时宠物隐藏。
  切到后台时默认隐藏、回到前台后恢复；可在设置中单独调整焦点切换行为。
  操作宠物自己的菜单不会触发失焦隐藏。目标关闭则解除绑定。
- 设置 →“形象与摄像头”→“吸附软件焦点切换”支持：失焦隐藏、返回显示（默认）；
  失焦生气、返回开心（约 2.5 秒）；保持显示、不改变表情。对所有吸附软件生效，不要求目录锁定，
  保存后立即生效并记住选项。选择保持显示或表情模式后，宠物仍置顶跟随绑定窗口，可能显示在其他软件上方。
  焦点与标签页规则独立：任一规则要求隐藏就隐藏，任一规则要求生气就优先于返回开心。
  目标最小化、隐藏及用户手动隐藏仍优先。
- “吸附后自主活动”默认开启，可在设置的“形象与摄像头”页或吸附后的右键菜单中关闭。
  宠物会沿窗口边缘散步（优先前往标题栏），并偶尔探头、翻身或睡觉。窗口变窄时会重新约束在可用轨道上；
  快速移动窗口时会产生有上限的滞后偏移，然后平滑追回。软件最大化后改为沿所在屏幕边缘活动，
  还原窗口时会平滑回到原先选定的吸附位置。
- 从绑定位置拖动不足 40 个逻辑像素会回到原角落；拖得更远后松开可解绑，
  若命中其他窗口角落则重新绑定。拖动中按 Esc 取消并恢复拖动前的位置/绑定。
- 窗口吸附、鼠标跟随、屏幕贴边互斥。开始手动拖动会停止鼠标跟随。
  托盘“显示小猫”会解除现有窗口绑定并显示宠物，避免目标隐藏时无法找回。
- 吸附点按窗口可见边框计算，允许宠物位于软件内部或跨在边框上，不提供完全位于软件外部的位置。多显示器按目标所在屏幕
  的缩放比例换算坐标；跨不同 DPI 屏幕拖动的边界场景仍建议实际验证。
- 最大化软件的边缘与屏幕边缘重合时，只有鼠标距当前屏幕边缘小于判定距离时才会进入
  紫色的屏幕贴边候选，其他位置仍按蓝色的软件吸附处理。判定距离默认为 5px，可在
  设置 →“形象与摄像头”→“屏幕边缘判定”中调整。拖动时按住 `Shift` 强制软件吸附，
  按住 `Ctrl` 强制屏幕贴边。
- 资源管理器目录每秒在后台刷新，可在吸附菜单查看、复制。复制时重新查询，不操作目录文件。
  “此电脑”“快速访问”等虚拟位置仅显示名称，不提供伪造的磁盘路径；Windows 11 多标签页
  仅在能够确认活动视图时返回路径，否则显示“当前标签页无法确认”。第三方文件管理器暂不支持。
  Windows 11 标签页结合浏览器子窗口顺序判断，不能仅凭“可见”标志判断；这是资源管理器特定
  的兼容处理，并非公开的标签页选择接口，未来系统版本变动可能需要适配。
- 更新依赖后用 `run.bat` 启动；若提示缺少 pywin32，请用该脚本对应的 Python 执行
  `-m pip install -r requirements.txt`。目录读取失败不影响吸附和其他功能。
- 绑定及吸附提示开关仅本次运行有效，不写入 `config.json`。

#### 锁定资源管理器当前标签页目录

先将宠物吸附到资源管理器，在目标标签页打开要保留的真实文件夹。右键宠物直接选择
“锁定当前标签页目录（导航后退回）”，或从托盘的“软件窗口吸附”子菜单选择该操作。启用时重新读取当前活动标签页，
不直接使用菜单中缓存的路径；成功后菜单显示锁定目录，并提供“解除目录锁定”。

- 每约 0.5 秒检查一次。允许打开锁定根目录及任意层级的子目录；进入父目录、同级/其他目录、
  其他磁盘或虚拟位置时，尝试导航回锁定根目录。路径按 Windows 目录边界判断，名称前缀相似的同级目录不算子目录。
  新目录可能短暂显示，接口繁忙时可能延迟；这不是导航前拦截，也不是文件访问权限或安全防护。
- 锁定绑定到启用时的具体标签页。其他标签页、新建标签页及其他资源管理器窗口不受限制；
  切走时暂停检查，切回原标签页后继续。不会强制切回原标签页。
- 仅可从能确认的真实文件夹启用；“此电脑”等虚拟位置或活动标签页无法确认时不能启用。
- 原标签页关闭/无法识别、资源管理器接口出错、宠物解绑或重新吸附到其他窗口、程序退出都会解除。
  仅切换同一窗口的吸附角落不会解除。锁定状态不保存，下次启动需手动开启。
- 恢复操作有 2 秒间隔；连续 3 次未能恢复会解除锁定并提示，避免反复跳转。
  若锁定文件夹被删除、改名或失去访问权限，请检查目录后重新启用。
- 解除锁定会停止后续检查；已经交给资源管理器执行的那一次导航无法撤回。
- 设置 →“形象与摄像头”→“锁定标签页切换”可选择：切走生气、返回开心（默认）；
  切走隐藏、返回显示；不改变角色表现。猫类和人类均支持表情变化，返回开心持续约 2.5 秒。
  保存后对当前锁定立即生效，选项写入配置。仅启用目录锁定时生效；隐藏宠物不停止目录检查。
  解除锁定会清除标签页相关表情/隐藏状态；软件焦点行为和手动隐藏规则仍生效。

### 截图与翻译

截图框选过程中会在鼠标附近显示带中心十字准星的像素放大图；选区角落显示尺寸，放大镜
旁按以下格式实时跟随显示取色信息：

```text
坐标: (542, 316)
HEX: #FF8844
RGB: (255, 136, 68)
```

选区确认后可拖动四条边或四个角调整宽高，也可按住选区内部整体移动。

贴图可用左键拖动，滚轮缩放，双击关闭；右键可复制图片、恢复原始大小或关闭。
OCR 默认使用进程内 RapidOCR，不能关闭，也可切换为兼容 OpenAI `chat/completions` 图片
消息格式的第三方服务；翻译默认关闭，可单独配置 OpenAI-compatible 或讯飞机器翻译。
截图仅在用户点击 OCR/翻译后处理或发送；API Key 保存在本机配置文件中，并在程序日志中
脱敏。

翻译结果支持右键切换“原图绘制结果”和“弹出显示结果”：原图绘制模式右键选择
“切换为弹出显示结果”；弹窗的图片区域、文字区域或背景右键选择“切换为原图绘制结果”。
切换复用本次翻译的原图和译文，不重复请求接口；设置页的结果模式只决定首次展示方式。
结果默认按图片实际尺寸显示，小图不放大；接近屏幕边界的大图按比例缩小，弹窗会预留
右侧文本区的宽度。弹窗高度由图片和按钮所需的最低高度决定，不再固定为至少 360 像素。
在弹窗左侧滚动鼠标滚轮以鼠标所在位置为中心缩放图片，窗口和右侧文本区大小不变。
放大后超出左侧显示区时可按住左键拖动图片，或通过滚动条查看；右侧滚轮仍用于滚动文字。
纯图片贴图也以鼠标位置为缩放中心，滚轮会调整图片窗口大小。
结果弹窗的“切换原文/译文”“一键复制全部”和“关闭”按钮提供悬停高亮、按下反馈及
提示文字。复制全部成功后，当前屏幕上方居中显示“已复制全部文字”，约 1.8 秒后自动
消失，不抢占输入焦点。

## 代码结构

`main.py` 只负责调用启动函数，核心代码位于 `coolcat/`：

| 路径 | 职责 |
|---|---|
| `coolcat/entrypoint.py` | QApplication 初始化与程序启动 |
| `coolcat/cat_window.py` | 主窗口、交互与监控协调 |
| `coolcat/runtime.py` | 基础依赖、日志、尺寸和配色常量 |
| `coolcat/config.py` | 默认配置及配置读写 |
| `coolcat/effects.py` | 粒子动画效果 |
| `coolcat/detection/camera.py` | 摄像头采集、人体/姿态检测与调试画面 |
| `coolcat/platform/windows.py` | Windows 窗口枚举、切换与全屏识别 |
| `coolcat/platform/hotkeys.py` | 全局快捷键 |
| `coolcat/platform/autostart.py` | 开机启动管理 |
| `coolcat/ui/` | 聊天层、预览窗口和设置对话框 |
| `config/config.json` | 源码运行配置 |
| `assets/` | 图标及模型文件 |
| `packaging/` | PyInstaller 与 Inno Setup 配置 |
| `tools/` | 开发辅助脚本 |
| `tests/` | 测试脚本 |

`coolcat/common.py` 是旧代码迁移期间的内部聚合层，不包含独立业务逻辑。

## 配置

源码运行读取 `config/config.json`；打包后读取 EXE 同目录的 `config.json`。安装包不附带
`config.json`：首次启动缺少配置文件时使用内置默认值，用户保存设置后才会在 EXE 同目录
创建该文件。程序不再提供默认设置密码：只有用户在“安全”页面手动设置密码后，后续进入
设置才需要验证；第一次设置密码不要求输入旧密码。内置检测默认值为 YOLO 和
`yolo26n-pose.onnx`。

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `model` | `yolo` | 检测模型：`yolo` 或 `hog` |
| `yolo_model` | `yolo26n-pose.onnx` | YOLO ONNX 权重文件名 |
| `yolo_conf` | `0.4` | 人体检测置信度 |
| `pose_kpt_conf` | `0.5` | 姿态模型头部关键点置信度 |
| `dedup_iou` | `0.55` | 重复检测框合并阈值 |
| `trigger_count` | `2` | 触发人数阈值 |
| `sustain_sec` | `1.5` | 触发需要持续检出的秒数 |
| `trigger_cooldown_sec` | `10.0` | 自动切换后的冷却时间，`0` 表示关闭 |
| `camera_index` | `0` | OpenCV 摄像头编号 |
| `cat_scale` | `1.0` | 宠物缩放比例，范围 `0.01`～`2.0`（1% 为防止零尺寸的技术保护值） |
| `character_category` | `cat` | 一级形象类别：`cat`（猫类）或 `human`（人类） |
| `cat_style` / `cat_color` | `0` / `0` | 当前类别下的形象及猫类配色索引 |
| `target_exe` / `target_title` | `devenv` / `visual studio` | 自动切换的目标程序 |
| `maximize_target` | `false` | 是否最大化目标窗口 |
| `hotkey` | `Ctrl+Alt+V` | 全局快捷键 |
| `hotkey_enabled` | `true` | 是否注册全局快捷键 |
| `monitor_hotkey` | `Ctrl+Alt+M` | 启用/禁用监控的全局快捷键 |
| `monitor_hotkey_enabled` | `true` | 是否注册监控开关快捷键 |
| `monitor_effect_size` | `220` | 左上角渐变闪烁范围（像素） |
| `screenshot_hotkey` | `Alt+A` | 区域截图、OCR、翻译和贴图快捷键 |
| `screenshot_hotkey_enabled` | `true` | 是否注册全局截图快捷键 |
| `screenshot_ocr_provider` | `rapidocr_local` | OCR 服务：`rapidocr_local` 或 `openai_compatible`，不可关闭 |
| `screenshot_result_mode` | `image` | 仅控制翻译；OCR 使用非模态无标题栏原图+右侧文字面板 |
| `screenshot_ocr_api_endpoint/key/model` | 空 | 云端 OCR 独立接口、密钥和图片模型 |
| `screenshot_translate_provider` | `disabled` | 翻译服务：关闭、OpenAI-compatible、讯飞旧版或讯飞 2.0 |
| `screenshot_translate_api_endpoint/key/model` | 空 | 翻译服务独立接口、密钥和模型 |
| `screenshot_xfyun_endpoint` | `https://itrans.xfyun.cn/v2/its` | 讯飞机器翻译接口 |
| `screenshot_xfyun_app_id/api_key/api_secret` | 空 | 讯飞翻译鉴权配置（仅保存在本机） |
| `screenshot_xfyun_v1_endpoint` | `https://itrans.xf-yun.com/v1/its` | 讯飞机器翻译 2.0 接口 |

### 本地 RapidOCR（小体积方案）

安装依赖后，在设置 →“截图与贴图”→“OCR 服务”选择
“本地 RapidOCR SMALL（进程内推理）”即可。RapidOCR 3.9 以上的 wheel 已包含默认中英
SMALL ONNX 模型，不需要下载或启动额外 EXE。

本方案直接把截图字节传给 `RapidOCR()`，不启动外部进程、不监听端口，截图不会上传。
RapidOCR 本身不提供翻译；需要截图翻译时，应另外配置独立的翻译服务，OCR 仍可保持本地
RapidOCR。

设置页支持实时预览；“保存并应用”不会关闭设置页。监控默认启用，暂停后会释放
摄像头。调试截图保存在 `debug_shots/YYYYMMDD/`，程序只清理由自身创建的日期目录。

## 打包 EXE

```powershell
python packaging/build.py
```

`build.py` 会依次完成：

1. 生成应用图标；
2. 使用 `packaging/CoolCat.spec` 执行 PyInstaller `onedir` 打包；
3. 将两个 ONNX 模型复制到 `dist/CoolCat/assets/models/`；
4. 检查最终 EXE 和必需模型是否存在。

输出程序位于 `dist/CoolCat/CoolCat.exe`。运行时资源布局如下：

```text
dist/CoolCat/
├── CoolCat.exe
└── assets/models/
    ├── yolo26n.onnx
    └── yolo26n-pose.onnx
```

`config.json` 不属于打包目标，首次保存设置时才会生成。不需要手动执行 PyInstaller 或
复制模型；若模型缺失，构建脚本会列出缺失文件并停止。若无法删除旧输出目录，请先退出
仍在运行的 CoolCat 程序。

## 常见问题

- **ONNX Runtime DLL 初始化失败**：入口会在 PyQt5 前预加载 ONNX Runtime；YOLO
  与本地 OCR 共用同一套 CPU 推理运行时。
- **打包时扫描 Torch/ONNX 后崩溃**：请通过 `python packaging/build.py` 构建，不要直接
  对 `main.py` 运行 PyInstaller；构建脚本会使用排除无关推理后端的专用 Spec。
- **YOLO 检测失败**：确认权重位于 `assets/models/`；失败时程序会回退 HOG。
- **找不到摄像头**：检查 `camera_index`，并确认目标摄像头未被其他应用独占。
