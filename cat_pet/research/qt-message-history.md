# Qt 消息与多页历史读取调查

## 产品接入（最新状态）

历史读取现按消息条数上限控制：设置 `wechat_history_messages`，默认 100，可选 1～1000。历史模式不再受旧 `wechat_history_pages` 限制；从当前阅读位置向上读取。时间标签不计数，非文本气泡占位计为一条；超额保留最近 N 条和关联时间标签。

连续三次滚动未取得更早内容时停止，但不声称服务器无更多历史。用户操作、读取错误、无法确认页间重叠及 5 分钟/1000 次滚动保护仍可提前停止，显示实际条数及原因。历史逻辑 10 项测试与设置界面测试通过；不等同于真实客户端多页端到端通过。

单页 Qt 消息读取已接入 WeChatAnalysisWorker，UIA 无法读取会话时回退；按可见气泡分组，保留时间标签，未知消息显示占位，不假定发送人或稳定消息 ID。读取使用已验证的 XTextView 元对象及内部 Text getter 存储链，不调用内部函数。当前微信实测读取成功，返回 84 字符。

新增右键“向上滚动读取历史（无需 AI）”，设置中的页面上限已启用。向可见且无遮挡的消息区域发送有界滚轮请求，等待内容稳定；按唯一且至少两项的有序重叠合并，保留重复消息。身份变化、用户输入、超时、无变化或无法确认重叠时停止并提示，结果不会声称已读完整历史。读取后停留在滚动位置。

多页实测尚未完成：尝试时在初始读取后检测到用户输入，正确取消，未执行滚动。6 项历史合并/取消测试、8 项原读取测试和 39 项吸附测试通过。列表对象身份不等同稳定会话业务身份，因此此功能不可作为无人值守监听或自动回复的数据源。

## 正文取值路径已实测

解析 XTextView 静态元对象 RVA 0x8b54db8（Qt 元数据 revision 8），属性 0 为 Text，类型 QString。静态 metacall RVA 0x8d8a30 的取值路径调用 RVA 0x1e21c70。

后者读取 XTextView +0x3e0 指针，再解引用为内部文本对象，通过虚表 +0x150 取内容。运行时已核对该槽为 RVA 0x2370fe0；反汇编确认它复制内部对象 +0x90 的 MSVC std::string（+0xa0 为长度，+0xa8 为容量，容量小于 16 时内联存储）。

按此路径只读内存、校验长度上限与前后头部一致性后，已读取当前会话中的真实正文、时间标签及通话时长；不在研究文档保存私人聊天正文。尚未按气泡完成结构化分组；500 节点遍历有上限，不能称为完整单页。

新增 tools/inspect_qt_properties.py 用于复现属性元数据解析，probe 的 --messages --text-fields 用于复现取值路径验证。尚未接入产品正文读取或翻页；不调用虚函数、不写进程内存。

状态：消息列表对象已定位，正文解析和翻页尚未实现。当前记录不代表功能已可用。

## 已验证证据

沿 chat_message_list 字符串引用 RVA 0x1bd69db，核对调用构造候选 0x221dc90。对象分配大小 0x2d0，保存至所属对象 +0x258；名称通过此前已核对的存储路径设置。

构造函数写入主虚表 0x8efbed8，以及 +0x10=0x8efc118、+0x30=0x8efc158、+0x68=0x8efc188。

运行 tools/probe_qt_instances.py --messages，在 PID 5432 中发现匹配对象 0x1fc335f1fe0，名称精确匹配 chat_message_list，父链对应窗口 0x101086，全部祖先可见，客户区相对起点 (300,80)。另一个相同虚表对象名称不同且不可见，不能采用。

遍历消息列表 274 个后代，找到一个 chat_bubble_item_view 名称匹配对象，但其自身可见位为假。不能据此宣称当前可见消息已读取，也不能把隐藏、回收池中的气泡当作有效消息。

## 实现顺序

1. 确认消息模型中的正文、消息类型、发送人、时间和稳定消息 ID；只解析已确认类型，未知类型保留占位，不能用对象地址当消息 ID。
2. 每次读取记录当前会话身份，在读取前后复核。先读取当前已加载模型，可能多于屏幕可见范围；必须验证排序和隐藏/复用项排除规则。
3. 单独实现受控向上滚动或已验证加载接口。在 UI 线程发起界面动作，等待模型变化后读取；用户切换会话或手动操作时取消。内存只读本身不会加载未驻留的历史。
4. 优先按稳定 ID 合并多页；没有稳定 ID 时保留重复消息并使用有序重叠区核对，不按正文全局去重。页间无法确认重叠时标记不连续。
5. 有效页数、超时、取消和到顶条件分别统计；保留截图功能隔离和原窗口边缘吸附。未取得可靠正文前不启用设置中的历史页数按钮。

本轮未执行翻页、未输出聊天正文、未修改进程内存。
